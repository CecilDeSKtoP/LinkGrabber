# Link Grabber (Chrome Extension)

`Ctrl + 마우스 좌클릭 드래그`로 웹페이지의 원하는 화면 영역을 지정하면, 영역 내의 모든 링크(URL)를 추출하여 클립보드에 복사해 주는 크롬 확장 프로그램입니다.

---

## 🚀 주요 기능

- **마우스 드래그 영역 선택**: `Ctrl` (Mac: `Cmd`) 키를 누른 상태에서 마우스를 드래그하여 직관적으로 사각 영역을 선택.
- **실시간 링크 카운트 뱃지**: 드래그하는 동안 마우스 커서/선택 상자에 감지된 링크 개수가 실시간으로 표시.
- **클립보드 자동 복사**: 마우스 버튼을 놓으면 영역 내의 모든 URL이 줄바꿈(`\n`) 형식으로 클립보드에 즉시 복사.
- **중복 URL 자동 제거**: 선택 영역 안에 동일한 링크가 여러 개 있더라도 중복 없이 1개씩만 깔끔하게 복사 (설정에서 On/Off 가능).
- **무효 링크 자동 필터링**: `javascript:`, `mailto:`, 단순 앵커(`#`), 빈 링크 등을 자동으로 감지하여 제외.
- **결과 알림 토스트**: 복사 완료 시 추출된 링크 수와 함께 세련된 플로팅 알림 노출.
- **옵션 설정 팝업**:
  - 확장 프로그램 On/Off 스위치
  - 단축키 조합 선택 (`Ctrl/Cmd`, `Ctrl 전용`, `Alt`, `Shift`)
  - 중복 URL 제거 옵션
  - 누적 복사 통계 및 초기화 기능

---

## 📦 크롬 브라우저에 설치하는 방법 (개발자 모드)

1. 크롬 브라우저를 열고 주소창에 `chrome://extensions` 를 입력하여 확장 프로그램 관리 페이지로 이동합니다.
2. 우측 상단의 **개발자 모드(Developer mode)** 스위치를 켭니다.
3. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** (Load unpacked) 버튼을 클릭합니다.
4. 이 프로젝트 폴더(`linkGrabber`)를 선택합니다.
5. 크롬 툴바에 **Link Grabber** 아이콘이 추가됩니다.

---

## 🎯 사용 방법

1. 링크를 추출하고 싶은 웹페이지(또는 포함된 `test/test_page.html`)로 이동합니다.
2. 키보드의 <kbd>Ctrl</kbd> 키(Mac: <kbd>Cmd</kbd>)를 누른 채 마우스 왼쪽 버튼으로 원하는 영역을 드래그합니다.
3. 파란색 선택 사각형 내에 감지된 링크 개수가 표시됩니다.
4. 마우스 버튼을 놓으면 클립보드에 URL 목록이 복사됩니다.
5. 메모장이나 다운로더(IDM, JDownloader, aria2 등)에서 <kbd>Ctrl + V</kbd> 로 붙여넣기합니다.
6. *참고: 드래그 도중 <kbd>Esc</kbd> 키를 누르면 취소됩니다.*

## 📂 파일 구조

```
linkGrabber/
├── manifest.json         # Manifest V3 확장 프로그램 설정 파일
├── content/
│   ├── content.js        # 드래그 이벤트, 영역 판별, URL 추출, 클립보드 복사
│   └── content.css       # 선택 상자 및 토스트 알림 디자인
├── popup/
│   ├── popup.html        # 확장 프로그램 팝업 설정 화면
│   ├── popup.js          # 설정값 저장/동기화 로직
│   └── popup.css         # 팝업 스타일
├── icons/                # 16px, 48px, 128px 고해상도 아이콘
└── test/
    └── test_page.html    # 링크 추출 및 클립보드 붙여넣기 테스트 페이지
```
