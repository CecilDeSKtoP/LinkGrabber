Link Grabber 테스트 페이지 Chrome Extension

아래 영역에서 Ctrl + 마우스 좌클릭 드래그를 수행하여 링크가 정상 추출되는지 확인하세요.

💡 테스트 방법:

  1. 키보드의 Ctrl (Mac은 Cmd 가능) 키를 누른 상태에서 마우스 왼쪽 버튼을 누르고 드래그합니다.
  2. 원하는 영역을 드래그하면 파란색 선택 상자와 링크 개수 뱃지가 표시됩니다.
  3. 마우스 버튼을 떼면 해당 영역 내의 모든 링크가 클립보드에 복사되고 토스트 알림이 나타납니다.
  4. 하단의 클립보드 확인 영역에 Ctrl + V 로 붙여넣어 확인합니다.
